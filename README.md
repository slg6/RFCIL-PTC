1. In `main.py`, specify the configuration files, e.g. `wa.json`, `tagfex.json`, etc.  
2. In the algorithm files, e.g. `wa.py`, `tagfex.py`, etc., adjust the `epoch` settings.  
3. In `train.py`, configure the dataset to run, the number of incremental learning tasks, and the initial number of classes.  
4. Run `main.py`.



Note: this code is based on [ET-Bert](https://github.com/linwhitehat/ET-BERT), [UER-py](https://github.com/dbiir/UER-py) and [PyCIL](https://github.com/LAMDA-CL/PyCIL). Many thanks to the authors.
